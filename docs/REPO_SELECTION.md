# Chọn repo để làm video

## Nguyên tắc
- Repo nào hay thì làm. **Ưu tiên** repo dễ ứng dụng cho **sinh viên, giáo viên, nhân viên văn phòng**; không bắt buộc đề tài văn phòng (repo dev như Multica vẫn OK).
- Phải kiểm chứng: giấy phép, có bản trả phí không, cần API key không, có tiếng Việt không, chạy trên hệ điều hành nào, repo còn hoạt động không.
- Nếu chủ kênh bác một repo: **không hỏi lại dài dòng**, chọn repo khác dứt khoát (đừng làm tiếp repo bị bác, đừng đề xuất lại).
- Nguồn gợi ý: các trang tổng hợp repo thịnh hành tuần/tháng (trendshift, các issue "AI Open Source Trends", danh sách weekly top repos); `gh search` có thể bị chặn trong sandbox → dùng web search.
- Tham khảo thành công của kênh: video OfficeCLI (AI tự làm Word/Excel/PowerPoint bằng 1 lệnh, ~11k view).
